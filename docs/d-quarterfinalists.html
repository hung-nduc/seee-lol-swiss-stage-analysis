How to read the player radars

Six tournament stats per player: KDA, KP (kill participation), Dmg/min (damage to champions per minute), Dmg % (share of team damage), Gold/min and Survival (deaths per game, reversed: fewer deaths = further out). Each axis is a percentile among all players of the same position in the Swiss Stage (players with at least 2 games there), so a support is compared with supports. Outer edge = best in that position, dashed ring = position median. Damage uses only games with a damage column (not LS13, LS33). A player with 1 game is marked small sample. Hover a radar for the actual values.
